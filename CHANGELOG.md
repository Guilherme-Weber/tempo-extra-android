# Changelog

## [v1.1a] - 2022-06-25

Versão final entregue no Projeto Integrador V (UNIFACEAR, 2022).

### Funcionalidades

- Login com três perfis de acesso: administrador, coordenador e aluno.
- Cadastro de coordenadores pelo administrador, com vínculo ao curso.
- Cadastro de alunos pela tela inicial, com vínculo ao curso.
- Abertura de pedidos de validação de atividades complementares pelo aluno (Capacitação, Produção Científica, Atividades Humanísticas e Vivência Profissional Complementar).
- Análise dos pedidos pelo coordenador, com deferimento (informando as horas) ou indeferimento.
- Atualização automática do saldo de horas do aluno.
- Consulta dos pedidos e do total de horas pelo aluno.
- Armazenamento local dos dados com Room (SQLite).

### Requisitos

- Android 5.0 (API 21) ou superior.

### Observações

- O APK é assinado com a chave de debug e serve para demonstração. Para instalá-lo, é preciso permitir a instalação de apps de fontes desconhecidas.
- Os dados ficam apenas no dispositivo.
